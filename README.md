# LIT DEX Tracker

Live web app for Lighter (LIT) traders: portfolio, PnL calendar, stats, and a $1K → $1M doubling ladder.

**Repo:** https://github.com/fwu713spam-cloud/lit-dex-tracker

**Site (after Pages is on):** https://fwu713spam-cloud.github.io/lit-dex-tracker/

## Use it

Open the GitHub Pages URL on desktop or iPhone. On iPhone: Safari → Share → Add to Home Screen.

## Features

- Portfolio equity, 1D / 7D / 30D PnL, live Lighter tape
- Interactive 10-double path from $1,000 to $1,000,000
- Monthly PnL heatmap calendar
- Win rate, profit factor, expectancy, drawdown
- Optional Lighter L1 address lookup
- Local-only storage in the browser
